# EcoHorizonte

Sitio educativo sobre el medio ambiente desarrollado con HTML, CSS y JavaScript.

## Uso

Abre `index.html` en un navegador. No necesita instalación ni compilación.

Incluye cinco apartados independientes, imágenes locales, paisajes interactivos, diseño adaptable y un plan ambiental descargable. Consulta `LEEME.txt` para más detalles y créditos.
